# 🔒 Politique de sécurité

## Versions supportées

| Version | Supportée |
|---|---|
| 0.3.x | ✅ |
| < 0.3 | ❌ |

## Signaler une vulnérabilité

Si vous découvrez une vulnérabilité de sécurité, veuillez **ne pas** créer une issue publique.

Envoyez plutôt un email à : **baye.cheikh@example.com**

### Ce que nous demandons :

1. **Description** de la vulnérabilité
2. **Étapes** pour reproduire le problème
3. **Impact** potentiel
4. **Suggestion** de correctif (si possible)

### Notre engagement :

- Accusé de réception sous **48 heures**
- Évaluation et plan d'action sous **7 jours**
- Correctif déployé sous **30 jours** (selon la gravité)

## Bonnes pratiques appliquées

- ✅ Aucun secret en dur dans le code source
- ✅ Variables d'environnement pour les configurations sensibles
- ✅ Utilisateur non-root dans le conteneur Docker
- ✅ Dépendances régulièrement mises à jour
